# 網頁小遊戲

單檔 HTML 小遊戲，手機和電腦的瀏覽器都能直接開，不需要安裝。

- `index.html`：五子棋。可對電腦，也能連線對戰：一人按「建立房間」取得四碼代碼，傳給朋友，朋友輸入代碼後按「加入」。使用 PeerJS 點對點連線，不需要登入。
- `minesweeper.html`：踩地雷，三種難度，長按（電腦按右鍵）插旗。

## 用 GitHub Pages 開啟

Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)`，等一兩分鐘後：

- 五子棋：`https://mylove332000-cloud.github.io/minesweeper-gomoku/`
- 踩地雷：`https://mylove332000-cloud.github.io/minesweeper-gomoku/minesweeper.html`

免費方案的 GitHub Pages 需要公開儲存庫。
